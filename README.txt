GTA _ VI  

Files:
- index.html: complete responsive website
- icon.png: original unofficial fan-style icon (if included)

Run locally:
Open index.html in a modern browser.

Publish:
Upload the contents of this folder to a static web host such as GitHub Pages, Netlify, or Cloudflare Pages.

Behaviour:
- First visit in a browser: short visual glitch, “YOU ARE GAY!”, “WAIT FOR THE SURPRISE…”, 60-second countdown, then surprise reveal.
- Second and later visits in the same browser profile: special confirmation message.
- The visit count is stored in browser localStorage. It is specific to that browser/device profile; clearing site data or using private browsing resets it.
- The countdown continues without sound unless the visitor taps ENABLE SOUND, because mobile browsers generally block sound until a user gesture.
- No network requests, analytics, permissions, background activity, or access to personal data.
